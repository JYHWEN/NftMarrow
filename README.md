# NftMarrow

Builds customizable patient information systems for medical professionals to manage patient records securely online.

The key benefits of using NftMarrow include:

- Builds customizable patient information systems
- for medical professionals to manage
- patient records securely online

## Key Features

- Builds customizable patient information systems
- for medical professionals to manage
- patient records securely online

## Technology Stack

- rust
- rust framework (Flask/Django/FastAPI or equivalent)
- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftMarrow.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure NftMarrow, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
